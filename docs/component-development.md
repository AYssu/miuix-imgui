# 新增与修改组件规范

先确认现有接口是否能够组合表达需求，再增加公开组件。
设计参考应指向具体的官方组件/交互；实现边界同步写入 [组件对照](miuix-components.md)。
当前为 C++/Dear ImGui 实现，不要求照搬 Compose 参数，也不能把未实现的窗口后端包装成已实现。

## 实现归属

| 文件 | 职责 |
| --- | --- |
| include/skui/skui.h | 公开类型、参数默认值、配对与生命周期契约 |
| src/skui/skui.cpp | 主题、基础控件、共享动画与输入处理 |
| src/skui/layout.cpp | 容器、顶栏、导航、Preference 与布局 |
| src/skui/components.cpp | 选择、级联菜单、颜色与数字等扩展组件 |
| src/skui/overlay.cpp | 浮层、遮罩、进退场与输入隔离 |
| src/skui/navigation.cpp | RouterView 绘制快照与页面动画 |
| src/skui/detail.h | 内部共享能力，不供宿主接入 |
| examples/gallery/gallery.cpp | 可发现、可操作的演示与分类搜索 |
| tests/skui_tests.cpp | 无设备的交互、布局和回归验证 |

新增 `.cpp` 后显式加入 `CMakeLists.txt`，不使用目录 glob 偷带测试或平台实现。
可移植组件不得读取 root 设备、启动进程、安装包或引用 Android 头文件。

## API 与交互

业务状态由调用方持有，组件返回本帧是否发生变化/操作；定义清楚空列表、无选中值、
非法范围、空文本和禁用项的行为。公开指针参数注明所有权、容量、单位与有效期。
稳定 ID 使用宿主 scope，不把显示文字、列表索引变化或临时内存地址当作唯一持久身份。

统一使用 `Dp`、主题颜色、公共间距和图标；验证深色/浅色、缩放、长文本及窄屏。
命中区域必须跟随视觉位置和裁切边界，按下后移出再释放不能触发动作。
滚动、拖动、输入焦点和父容器的手势应明确归属，不能为控件交互吞掉整个页面的滚动。
能复用 ImGui 原生输入语义的按钮继续保留键盘激活与焦点反馈。
按压底色统一通过 `detail::InteractionFeedback` 计算：只响应当前控件拥有的按压，
移出后取消，触屏松手后淡出；鼠标/笔的悬停与业务选中态单独保留。
圆角反馈应与控件边界一致，验证纹理圆角和顶点抗锯齿两条路径，避免淡出时透明度重复相乘。

## 动画与浮层

- 离散状态使用共享 `detail::Animate` 或现有同类组件的生命周期；按帧时间推进，不按固定帧数递增。
- 展开和收起都要有过渡，支持中途反向。退出期间保留内容和布局裁切，完成后才移除绘制。
- 连续输入如 Slider、HSV/alpha 和窗口拖动立即使用当前帧输入值，不增加追赶延迟。
- 浮层统一经由 `BeginOverlay/EndOverlay` 管理背景遮罩和层级；退出时隔离输入，避免内容误触。
- 输入隔离不要用 DisabledAlpha 替代，真实禁用项与普通退场内容的视觉状态必须区分。
- 短列表按内容自适应，无溢出时不出现滚动条；长列表、窄屏级联菜单需验证边缘定位和滚动。
- `animations=false` 下立即到位。静态 Text、Divider 等无需人为增加独立进场。

浮层的现有时长与行为边界见 [组件对照](miuix-components.md)。

## 演示与验收

Gallery 为每个新组件提供合理分类、搜索关键词、默认可见入口和可观察的结果。
同类组件放在一起，说明普通/高级、Overlay/Window 的区别；不能只给一个名称或不可操作占位。
示例至少展示正常使用及关键边界，如禁用、长选项、溢出或空数据。

行为修复增加能复现原缺陷的测试。动画改动至少验证初态、变化中的中间态、结束态、
中途反向、退出无误触与关闭动画；使用多个 DeltaTime 验证时间行为。
直接输入需验证“输入、值、预览同帧”；弹层关闭需检查末帧残留和重新打开。
与现有测试相关的回归可扩展原测试，不机械地给所有静态封装各写一份同构测试。

完成相关 [测试门槛](testing.md)，同步公开头文件、Gallery、组件对照和必要的接入示例后提交 PR。
